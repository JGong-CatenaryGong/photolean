### F1 [S2] 保真检查器的裸名回退可假 PASS：移入嵌套 namespace 的交付行仍计为 "word-for-word"

- **断言/期望**：README.md:13 起与 `theories/GRAPH-REPORT.md:30,447` 反复以 "语句保真 N/N（17/17 探针
  0 signature differences）" 作为交付语句逐字等于权威的证据；GRAPH-REPORT §10 的"诚实读法"只登记了
  一个盲区（签名比较到第一个 `:=` 为止，不覆盖定义体）。
- **证据**（变异实验，scratch 副本 `.lake/tmp/audit/`）：
  ```
  # 将 PhotoLean/KashaVavilov/Basic.lean 的 theorem rateData_mono 整体移入 namespace Sub … end Sub
  # （文件仍可通过 lean 解析；rateData_mono 的全限定名变为 …Sub.rateData_mono）
  $ python3 theories/BEP/probes/bep-fidelity.py --theory KashaVavilov
  delivered, word-for-word   : 29
  not delivered yet          : 0
  signature differences      : 0          # <-- 假 PASS：权威行 …rateData_mono 已不存在于原限定名
  $ proofs/scripts/lake build PhotoLean.KashaVavilov.Criterion
  error: ././././PhotoLean/KashaVavilov/Basic.lean:134:33: unknown identifier 'rateData_mono'
  error: build failed                     # <-- 构建层（下游引用）才是实际兜底
  ```
  机制定位（`theories/BEP/probes/bep-fidelity.py:198-211`，`_resolve`）：先精确匹配全限定名，失败后
  回退到"权威键集中唯一裸名"。**唯一性只在权威侧检查，交付侧不查**——于是任何嵌套 namespace 里的
  同名声明都能"顶包"。同一机制的对向实验（另加 `Sub.rateData_mono : True` 而保留真行）产生**假阳性
  signature difference**（误报方向亦实测）。
- **为何是缺陷**：验证词的作用域大于实际（分类 O4）。"word-for-word"被读作"权威那条全限定声明逐字
  存在于交付模块"，实测语义只是"存在某条同裸名且签名文本相同的声明"。Marcus 的 51/51 **全部**经此
  回退解析（其骨架声明在 `namespace PhotoLean.Marcus.Skeleton` 下，交付模块并无此 namespace），故
  该回退不是边角路径而是第一理论保真数的唯一来源。回退引入于 2026-09-22（探针 docstring 自述），
  前次审查（2026-09-21）未能覆盖。
- **最小复现**：见上（scratch 路径 `.lake/tmp/audit/`，变异后已 `git checkout --` 复原）。
- **当前树是否受害**：否。独立全限定名复核（本审查自写提取器，剥块注释 + namespace 栈）确认 17 个
  理论的全部骨架行都在交付模块中以正确限定名在案（Marcus 51 个裸名在交付侧唯一且无歧义）。
- **最小诚实修正（建议）**：`_resolve` 的回退分支同时要求"该裸名在**交付侧**也唯一"；或探针输出
  增加一行 "resolved via bare-name fallback: N rows" 使作用域显式化。

### A-7 轴 G 的 136 对枚举（脚本，本审查自写；结果见 F8）
```python
import itertools
nodes = ['M','H','B','K','S','G','SF','KV','SV','QY','FP','EGL','SS','IC','FO','EB','RACI']
def edge(a,b): return tuple(sorted([a,b]))
edges = {edge(*p) for p in [('M','H'),('M','B'),('H','B'),('K','M'),('S','B'),
    ('SF','M'),('SF','H'),('SF','B'),('KV','K'),('EGL','M'),('IC','M'),('QY','K'),
    ('SV','QY'),('FP','QY'),('EB','QY'),('FO','QY'),('EGL','K'),('SS','EGL'),
    ('IC','EGL'),('SV','FP'),('SV','FO'),('EGL','H'),('RACI','QY'),('RACI','EGL'),
    ('RACI','IC'),('RACI','M')]}
noedge = {edge(*p) for p in [('K','B'),('K','H'),('S','H'),('S','K'),('S','M'),
    ('G','M'),('G','H'),('G','B'),('G','K'),('G','S'),('G','SF'),('SF','K'),('SF','S')]}
for t,ps in {'KV':['M','H','B','S','G','SF'],'SV':['M','H','B','S','G','SF'],
    'QY':['M','H','B','S','G','SF'],
    'FP':['M','H','B','S','G','SF','SS','EGL','FO','EB'],
    'SS':['K','KV','SV','QY','FP','IC','FO','EB'],'IC':['K','KV','SV','QY','FO','EB'],
    'FO':['M','H','B','K','KV','S','SF','SS','EGL','IC'],
    'EB':['M','H','B','K','KV','S','G','SF','SS','FO']}.items():
    for q in ps: noedge.add(edge(t,q))
for p in ['H','B','S','G','SF','K','KV','SV','FP','SS','FO','EB']: noedge.add(edge('RACI',p))
allp = {edge(*p) for p in itertools.combinations(nodes,2)}
print('total',len(allp),'edges',len(edges),'noedge',len(noedge),'overlap',len(edges&noedge))
print('UNCOVERED', sorted(f"{a}-{b}" for a,b in (allp-edges-noedge)))
```
